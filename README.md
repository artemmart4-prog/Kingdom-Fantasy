# Kingdom Fantasy — Grand Grand Final

Пиксельное королевство вместо обычного главного экрана Android TV. Замок, горы, озеро, кораблики, анимированные герои и лавка купца. Управление обычным телевизионным пультом.

## Сезоны

В **Настройки → Время года** доступны автоматический режим и ручной выбор весны, лета, осени или зимы.

- Весна: зелёный пейзаж, розовое цветение деревьев и цветы.
- Лето: исходный зелёный пейзаж, дневные бабочки и ночные светлячки.
- Осень: жёлто-оранжевая растительность и восемь падающих листьев.
- Зима: заснеженная земля и замок, голые деревья, без насекомых. В режиме покоя вместо волка приходит белая лиса, останавливается и принюхивается.

Автоматические сезоны соответствуют северному полушарию: март–май, июнь–август, сентябрь–ноябрь и декабрь–февраль. Ручной выбор сохраняется. Он не меняет время устройства и фактическую погоду.

## Другие возможности

- День, вечер и ночь по часам устройства; дневные фонари выключены.
- Музыка королевства, ручной выбор мелодии и громкости; увеличенный аудиобуфер против заиканий.
- Погода Open-Meteo, отдельное отключение тумана. Погода и сезон видны также в окне лавки купца; осадки не закрывают карты.
- Герои, галерея, мини-игра «Три кружки», локальные достижения.
- Карточки Android TV для рекомендаций и недавних видео, если приложения их публикуют. Это не вход в аккаунт YouTube и не гарантия точного облачного прогресса.
- Встроенный поиск/браузер, приложения и настройки Android TV.

## Совместимость и производительность

Проверено на Xiaomi Mi TV Stick первого поколения, Android TV 9, 1 ГБ RAM. Минимальный API — 26. Производительность других устройств требует отдельной проверки.

Пейзаж кэшируется, число анимированных объектов ограничено; сезоны не добавляют новые полноэкранные буферы. В фоне и при выключенном экране анимации и музыка останавливаются. Музыка уступает аудиофокус другим приложениям.

## Управление

Стрелки — приложения; OK — открыть. Вниз — выбор героя, влево/вправо — предварительный просмотр, OK — применить открытого героя. После последней иконки вправо — лавка купца. Назад/Home — возврат. В лавке вверх — действия, влево/вправо — карусель карт.

Белая лиса доступна отдельно в **Настройки → Предпросмотр сцен**.

## Сборка на Windows

Нужны JDK 17 и Android SDK (Platform 35, Build Tools с aapt, d8, zipalign и apksigner). После установки официальных Android SDK Command-line Tools:

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_SDK_ROOT = 'C:\path\to\android-sdk'
./build.ps1
```

Результат: `build/kingdom-fantasy.apk`. Можно передать `-JdkRoot`, `-BuildToolsPath` и `-AndroidJar` явно. Для сборки без подписи: `-UnsignedOnly`.

Скрипт создаёт локальную отладочную подпись. Она не совпадает с подписью ранее установленной пользовательской сборки: установить её поверх другой подписи нельзя. Производственные ключи не публикуются. Не удаляйте рабочий лаунчер или штатные компоненты для экспериментов; сначала проверьте наличие доступного резервного Home.

Установка APK с компьютера при уже настроенном ADB:

```powershell
adb connect TV_IP:5555
adb install -r build/kingdom-fantasy.apk
```

Публичные исходники используют Berlin как пример города для погоды. Для своего города измените `CITY` и координаты в `WeatherSource.java`; автоматического определения местоположения нет.

## Проверки

`tests/SeasonRegressionTest.java` проверяет календарные границы, ручной выбор, зимнее отключение насекомых и траекторию лисы. `tests/GrandRegressionTest.java` проверяет освещение, разделение ТВ-карточек и паузу обновления в фоне. После сборки:

```powershell
javac -encoding UTF-8 -cp build/classes -d build/test tests/*.java
java -cp 'build/classes;build/test' SeasonRegressionTest
java -cp 'build/classes;build/test' GrandRegressionTest
```
